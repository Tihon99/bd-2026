# Анализ соревнований и сообщества Kaggle

Учебный проект: исследуем соревнования, участников, команды и ноутбуки Kaggle по открытому датасету [Meta Kaggle](https://www.kaggle.com/datasets/kaggle/meta-kaggle).

## Задачи

1. **Динамика соревнований** — число соревнований по годам, типы, призы, тематика и число участников/команд.
2. **Профили участников** — уровни, уход после первого соревнования, длительность активности.
3. **Команды и успех** — связь размера, опыта и ранних посылок с результатом.
4. **Популярность ноутбуков и датасетов** — голоса, просмотры и группы тегов.
5. **Прогнозная модель** — попадание в топ-10% по ранним признакам команды.

## Структура и запуск

CSV из Meta Kaggle размещаются в `data/raw/` и не коммитятся. Инструкция — `data/README.md`.

```bash
python -m venv .venv
pip install -r requirements.txt
bash scripts/download_data.sh
python -m src.build_dataset
jupyter notebook notebooks/
```
