# Устойчивость прогноза на новых соревнованиях

Проверка выполнена на датасете Meta Kaggle, выгруженном 6 ноября 2026 года: 458 878 команд из 303 Featured-соревнований. Для каждого из пяти seed применено групповое разбиение 80/20 по CompetitionId: в тесте каждого разбиения 61 соревнование.

| Модель | ROC-AUC, среднее ± SD | Диапазон ROC-AUC | PR-AUC, среднее ± SD |
|---|---:|---:|---:|
| constant | 0.500 ± 0.000 | 0.500–0.500 | 0.100 ± 0.000 |
| experience_rule | 0.602 ± 0.004 | 0.597–0.607 | 0.135 ± 0.001 |
| logreg | 0.641 ± 0.005 | 0.635–0.647 | 0.212 ± 0.008 |
| lightgbm | 0.657 ± 0.007 | 0.649–0.665 | 0.233 ± 0.011 |

LightGBM дал лучший средний результат в этих пяти разбиениях; разброс ROC-AUC между ними невелик. Это подтверждает устойчивость внутри выбранного среза и схемы разбиения, но не заменяет временную проверку и подбор параметров. PR-AUC сравнивается с долей положительного класса около 0.10. Результаты не следует интерпретировать как причинную связь.
