## Договорённости

- Каждый ноутбук — в `notebooks/`, с номером блока в названии.
- Общий код (загрузка, константы) — только в `src/`, в ноутбуках не копируем.
- Сырые данные в git не коммитим.
- Перед пушем — `git pull --rebase`.
